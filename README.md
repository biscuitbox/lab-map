# 특별실 물품 지도

학교 특별실의 보관장을 **칸 블록으로 조립**하고, 어느 칸에 무엇이 몇 개 있는지 여러 선생님이 함께 관리하는 웹사이트예요.
과학실에서 출발했고, 음악실·미술실·기술실·가사실·체육 창고에서도 쓸 수 있어요.

- 설치비·서버비 없이 **GitHub Pages + Firebase 무료 요금제**로 운영해요.
- **구글로 로그인하고 관리자가 승인한 선생님만** 내용을 보고 고칠 수 있어요.
- 빌드 과정이 없는 순수 HTML·CSS·JavaScript라서, **생성형 AI와 함께 고치기 쉬워요.**

> 처음 쓰는 분은 [사용설명서](help.html), 직접 설치하려는 분은 [설치 안내](SETUP.md), AI로 고치려는 분은 [AI 수정 안내서](AI_GUIDE.md)를 보세요.

## 할 수 있는 일

| | |
|---|---|
| **배치도** | 특별실 바닥 위에 보관장·탁자·교탁을 끌어서 배치하고 위치를 잠가요. 블록마다 ‘비커’, ‘플라스크’처럼 이름이 보여요. |
| **보관장 조립** | 실제 보관장처럼 칸 수를 맞추고, 빈 칸을 눌러 블록을 붙여요. 블록 색 = 분류(산, 염기, 유리기구…). 여러 칸 크기 블록도 돼요. |
| **물품 관리** | 수량, 최소 수량, 유효기한, 분류, 사진을 기록해요. 부족·기한 임박·만료를 자동으로 표시해요. |
| **찾기** | ‘염산’이라고 찾으면 배치도에서 그 보관장과 칸이 밝게 표시돼요. |
| **약품 안전** | CAS 번호, MSDS 링크, GHS 그림문자. 산과 염기, 산화제와 인화성 물질이 맞닿으면 보관 경고를 띄워요. (과학실이 아니면 끌 수 있어요) |
| **대여 기록** | 빌려간 곳과 반납 예정일을 적고, 연체를 표시해요. |
| **사용 통계** | 수량 변경이 자동으로 기록되어 한 해 사용량과 **내년 구입 추천**을 보여 주고 CSV로 내려받아요. |
| **QR 라벨** | 칸마다 붙일 라벨을 A4로 인쇄해요. 휴대폰으로 찍으면 그 칸이 바로 열려요. |
| **실수 방지** | 지운 직후 ‘되돌리기’, 30일 휴지통, 매일 자동 백업. 지난 백업과 비교해 필요한 것만 되살려요. |
| **다른 특별실** | 큰 제목과 ‘실험장’, ‘실험대’ 같은 부르는 이름을 설정에서 바꿔요. 특별실 종류별 추천 분류도 있어요. |

## 빠른 시작

1. 이 저장소를 **Fork** 하거나 파일을 내려받아 내 저장소에 올려요.
2. [Firebase](https://console.firebase.google.com)에서 프로젝트를 만들고 **Google 로그인**과 **Firestore**(서울 지역)를 켜요.
3. `js/config.js`에 Firebase 설정값과 관리자 이메일을 적어요.
4. `firestore.rules`의 관리자 이메일을 바꿔서 Firebase 콘솔 규칙 탭에 게시해요.
5. Firebase 승인된 도메인에 `아이디.github.io`를 추가해요.
6. 저장소 **Settings → Pages**에서 `main` 브랜치 `/ (root)`로 배포해요.
7. 사이트에 구글로 로그인 → **예시 데이터로 시작** 또는 **빈 지도로 시작**.

자세한 순서와 화면별 설명은 **[SETUP.md](SETUP.md)** 에 있어요.

## 폴더 구성

```
index.html         사이트 화면
help.html          사용설명서 (로그인 없이 볼 수 있음)
css/style.css      디자인 (밝은·어두운 화면)
js/config.js       ← Firebase 설정값, 관리자 이메일, 기본 제목
js/firebase.js     로그인·데이터베이스 연결
js/state.js        데이터, 계산, 저장 대기열, 특별실 이름 바꾸기
js/views.js        화면 그리기
js/actions.js      버튼·입력·끌기 동작
js/backup.js       휴지통·백업
js/photos.js       물품 사진
js/main.js         시작과 실시간 구독
data/sample.json   과학실 예시 데이터
firestore.rules    ← Firebase 보안 규칙
SETUP.md           설치 안내
AI_GUIDE.md        생성형 AI로 고칠 때 함께 주는 안내서
LICENSE            이용 조건 (MIT)
```

## 생성형 AI로 고치기

ChatGPT·Gemini·Claude에게 **[AI_GUIDE.md](AI_GUIDE.md)와 고칠 파일을 함께 첨부**하고 부탁하세요.

```
첨부한 AI_GUIDE.md의 규칙을 지켜서 고쳐 줘.
하고 싶은 것: 물품에 '구입일' 칸을 추가하고 재고 목록 표와 CSV에도 보이게 해 줘.
고친 파일은 전체를 다시 보여 주고, firestore.rules를 바꿔야 하면 알려 줘.
```

Claude Code를 쓴다면 `AI_GUIDE.md`를 `CLAUDE.md`로, Codex·Gemini CLI라면 `AGENTS.md`로 복사해 두면 자동으로 읽어요.

## 보안과 개인정보

- 데이터 접근은 `firestore.rules`가 서버에서 막아요. 사이트 코드가 공개돼도 승인된 계정만 데이터를 읽고 쓸 수 있어요.
- `js/config.js`의 Firebase 설정값은 공개돼도 괜찮은 값이지만, **다른 학교에 나눠 줄 때는 지우고** 주세요.
- 학생 개인정보는 넣지 않도록 해 주세요. 대여 기록의 ‘빌려간 곳’은 ‘2학년 3반 4모둠’처럼 모둠 단위로 적는 것을 권해요.
- 약품 보관 경고와 GHS 표시는 도움 기능이에요. 실제 안전 관리는 학교 지침과 각 약품의 MSDS를 따라 주세요.
